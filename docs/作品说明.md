# APT｜写这句话时，记得前面的事

带着个人上下文的 Mac 输入法，也连接手机的事件、原话和行动。

准备回复维修师傅，却记不清上次检查到哪一步。APT 从你授权保存的记录里找依据，帮你写进眼前的输入框。

| 这一步 | 虚构示例 |
|---|---|
| 之前写下 | 换过镜头，异常仍存在；防抖有没有问题还没确认。 |
| 现在想问 | 帮我回一下师傅，上次检查到哪一步了？ |

![APT 记忆候选历史预览](images/memory-card.png)

*虚构资料的原生界面预览（0.16.7 / 52）；历史示例，不代表本快照 0.17.16 / 76 的界面或模型实录。真实 demo 待录制。*

**查看依据 → 选择或修改 → 确认填入。最后发什么，由你决定。**

打字、口述和反复修改都在输入法里。需要时找回背景，减少重复介绍；材料不足就保留不确定性，不把「尚未确认」改成事实，也不把草稿称为已发送消息。

Mac 需 Apple Silicon、macOS 13+；AI 功能另需本机 Agent／来源服务、自己的门禁和模型。当前代码版本为 0.17.16 / 76；新 Mac 安装与真实键盘／跨应用效果待独立验证。iPhone / Watch 与 StepX 源码一并保留，但平台构建、设备安装和长期录音不能由 Mac 示例代替。
