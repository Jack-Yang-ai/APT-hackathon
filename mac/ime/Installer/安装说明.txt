APT 输入法 · Apple Silicon · macOS 13 或以上

1. 解压后，打开「安装 APT 输入法.app」。
2. 如果 macOS 提示无法验证：点「完成」，到「系统设置 → 隐私与安全性」点「仍要打开」，再确认打开。
   当前版本尚无 Developer ID 签名／公证，首次系统安全确认仍需本人完成。
   Apple 说明：https://support.apple.com/zh-cn/102445
3. 在安装窗口点「安装并启用」。程序自动备份、复制、注册、启用并检查后台连接。
   检测到仍指向旧 Echo 安装路径的系统输入法目录缓存时，会校验并移到私有备份，让系统重建；词库、记忆和应用数据保留。
   如果出现“允许启用 APT 输入法”的系统提示，请由本人决定是否允许。等待启用期间保留安装；完成后自动复查，也可点「重新检查」。
4. 显示「基础检查通过」后，点「打开试输框」。从菜单栏原生选择 APT，回到试输框输入 nihao 和空格，应得到「你好」。
5. 菜单没有 APT 时：点「打开键盘设置」→ 文字输入的「编辑」→ ＋ → 简体中文 → APT 输入法 → 添加并完成。
   若仍无法切换或没有候选词，查看原始诊断并重查；注册成功、进程运行及检查接口选中均不代表已能输入。
   如果只有某个 App 不能输入，APT 菜单只有灰色标题且没有「APT 设置…」，请保存内容后按⌘Q完全退出该 App，再重新打开；只关窗口不会结束旧连接。不必因此清空词库、记忆或退出系统登录。
   若检查仍未通过，点「安装／修复」；具体失败阶段和日志可在窗口查看，不需要手动运行终端命令。

安装位置：当前用户的 ~/Library/Input Methods/APT.app。普通用户目录安装无需管理员密码；迁移系统目录旧版时，macOS 会请求管理员验证。无需 Python、Xcode 或源码。
已有 APT 可直接升级，原设置、词库和记录保留。系统目录旧 APT 会先备份并撤旧注册，经管理员验证后移至 /Library/Application Support/APT IME Backups；用户启动项迁移至当前用户安装，取消授权则恢复旧安装。不要删除个人数据目录。
若“重新检查”提示尚未安装，点“安装／修复”。
安装器会留下日志、版本、原始错误、本版更新说明及旧包备份。

本包提供拼音输入和输入法界面。语音／AI 记忆功能仍需要每台 Mac 单独配置记忆 Agent 服务及个人授权。
指南：https://github.com/Jack-Yang-ai/APT-hackathon/blob/main/docs/MacBook-input-method.md

本包版本和实际验收范围见随包 CHANGELOG.md；拼音输入验收不代表语音、AI 或另一台电脑也已配置完成。
