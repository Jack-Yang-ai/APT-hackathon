# APT 输入法实现目录

本目录保存 InputMethodKit 壳、Rime 桥接、语音与记忆编排、设置和构建所需资源。`EchoMemoryIME` 是保留的实现／数据兼容名称，不表示当前应用仍使用旧品牌或旧输入源路径。

本快照基线的输入法构建号为 **0.17.16 / 76**，来源服务为 **0.2.4 / 11**。当前功能、快捷键与构建入口见 [输入法模块](../README.md)，配置见 [Mac 指南](../../../docs/MacBook-input-method.md)。本公开说明不转录历史私人安装、模型调用、输入记录或验收数量。

从仓库根目录使用 `scripts/build_ime.sh`、`scripts/verify_ime.sh` 和现行安装脚本，不直接覆盖已有用户数据。Rime、词库和 Vendor 组件保留各自许可及文件头通知，详见 [第三方声明](../../../THIRD_PARTY_NOTICES.md)。

公开源码不提供个人输入、声音、声纹、转写、标签、数据库、模型 Key 或服务门禁。测试与构建不等于真实键盘、跨应用或新 Mac 安装成功；实际结果单独记录。数据去向见 [隐私说明](../../../docs/Privacy-and-data.md)。
