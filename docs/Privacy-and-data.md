# 隐私、数据与使用者责任

## 源码不等于个人数据

公开仓库保留通用录音、语义处理、声纹提取／判决、受控注册与撤回、快照和迁移兼容代码；**不包含任何人的默认身份资料**。个人 seed、声纹模板、原录音、转写、说话人标签、真实输入、内容库、校准素材及衍生结果均不随源码发布。

声纹是敏感身份资料。使用者应只采集有权处理的声音：在自己的环境中，经授权的本地导出与受控注册入口建立自己的数据，保存在仓库外。原生「我 → 我的声音」要求核听样本、确认「是我」后登记；自动候选不直接入模板库。不要复制作者或另一台设备的身份库，不要用私人材料写公共测试。

通用模型权重与个人模板不同。随包的两个 ONNX（ReDimNet 说话人嵌入、Silero VAD）是上游 MIT 模型的本地转换产物，用于通用推理，不是任何人的声纹模板；上游链接、许可与发布字节 SHA-256 见 [第三方通知](../THIRD_PARTY_NOTICES.md)。声纹库初始为空：**公开仓库不附带任何人的默认身份资料**，需要使用时由你经授权入口自行采集与登记。个别依赖私人实地录音或私人 seed 的验收测试不在公开范围内，也不宣称通过。

## 各类功能的数据去向

| 功能 | 保存／发送范围 |
|---|---|
| 普通拼音 | 本机运行，打字不联网 |
| 本地输入草稿 | 自动记录默认关闭；开启后在本机保存。启用来源同步后发送至配置的后端 |
| 语音输入 | 麦克风音频送至配置的识别服务；可选轻整理将转写交给文字模型。Mac 临时语音不提供旧录音长期保留或重试库 |
| 记忆检索与生成 | 本机读取可用来源；可选本机 embedding；回答所需的问句、上下文和材料发送至配置的文字模型 |
| 后台整理／表达习惯 | 显式开启后按变化调用配置的模型，可能产生费用 |
| Watch／StepX 录音 | 原件沿采集链路保全；授权上传的音频、任务与模型请求由配置的后端和处理服务接收 |
| Mac 录音记忆 | 已同步原话作为版本化只读副本；不等于原始音频、手机正式库或声纹底库已迁移 |
| WithEcho／飞书 | 各自本人授权后只读接通实际材料；外部服务也有独立隐私与费用条款 |
| 本机诊断记录 | 可能含问句、来源与输出，不能视为“只有统计数字”；共享日志前需另行脱敏 |

本机 Agent 不代表模型也在本机。公开源码不提供匿名云服务、免费额度、默认模型 Key 或作者门禁。模型调用、后台整理、ASR 和重试可能付费，使用者应先确认配置和费用。

## 开关、删除与授权

- 「保存并同步到 APT」会开启来源同步，并可能立即上传旧草稿；已有数据时不能把它当作仅保存门禁按钮。
- 关闭同步暂停后续上传，**不等于删除既有云副本、撤回第三方模型请求或撤销外部授权**。关闭自动记录也不会自动清空历史。
- 原件、正式内容、只读副本和第三方材料各有删除入口与版本回执；断网时远端尚未收到修改，不能宣称全端已删除。
- 模型 Key 使用钥匙串；服务凭据放仓外配置并限制权限。StepX 的本机沙箱凭据存储不应被当成已证明加密，预览会话也不适合真实凭据。
- 每台设备保留独立身份，第二台 Mac 重新配置服务与授权。不要通过复制整库“同步”，也不要为了让状态变绿删除数据库。

## 公开构建不是私人库修复版本

公开导出移除了私人定点修补材料。数据库修复迁移 **v40／v42／v43／v44** 保留原迁移编号以维护序列，但其私人补丁为 no-op；这不是对现有私人库执行过或能够执行原修复的声明。通用 schema 迁移、录音和用户判断的保全逻辑继续保留。

**不要将公开构建作为既有私人库的修复／生产升级包。** 若需迁移自己的已有库，先独立备份并核 schema、数据版本和适用迁移，再取得自己的验证。被排除的私人回放、真实音频金标和标签不能复现，不宣称通过，也不生成合成替身冒充其验收。

新 Mac 安装、真实键盘／跨应用、双 Mac 查询、全天录音及耗电仍应分别实测。发现疑似泄露请先停止传播，报告文件位置和类型，不在公共 issue 重贴私人内容或完整凭据。
